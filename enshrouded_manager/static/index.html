Import Save Game

          
Use this after your dedicated server is installed. The manager backs up the current server save, then replaces it with the save you select.

          

            Where to look on your PC
            
Steam Cloud saves are usually in C:\Program Files (x86)\Steam\userdata\YOUR_STEAM_ID\1203620\remote.

            
Local saves with Steam Cloud disabled are usually in %USERPROFILE%\Saved Games\enshrouded.

            
If Steam is installed somewhere else, open your Steam folder, then browse to userdata\YOUR_STEAM_ID\1203620\remote.

          

          

            
Choose Save Folder From This PC
