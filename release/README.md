# Current Release

Current package: `ESM-Z-PythonRequired-v0.9.6.7a.zip`

Compatibility asset: `EnshroudedServerManager-PythonRequired-v0.9.6.7a.zip`

The full stable release includes optional EML integration. Mods must be EML-compatible, self-contained Lua patch mod ZIPs; see `docs/EML_MODS.md`. Older EML beta users should follow `docs/BETA_CHANNEL.md` to switch channels with mods preserved.

Both ZIPs contain the same files. Share the ESM-Z package with new users. The legacy-named asset exists only so v0.9.0 and older self-updaters can find this renamed release.

This package is for a Windows machine that already has Python 3.11 or newer installed.

Extract the zip, run `Run ESM-Z.bat`, then open:

```text
http://127.0.0.1:8080
```

The package includes install notes, user instructions, feature notes, release notes, and screenshots.
